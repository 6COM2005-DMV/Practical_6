# Practical 6: Distances and K-Means

6COM2005 Data Mining and Visualisation

## Aims
- Write distance functions: Euclidean, Manhattan, simple matching, and Jaccard.
- Implement K-Means yourself and check it against the lecture example.
- Use scikit-learn's KMeans on scaled data and compare the clusters with the species.
- Choose k with the elbow method and the silhouette coefficient.

## Files
- `Practical_6_T.ipynb`: the notebook you complete
- `6COM2005_DMV_Practical_6.docx`: the handout with all tasks
- `penguins.csv`: Palmer Penguins, 344 penguins, 8 attributes

## How to start
1. On this page, click **Use this template** → **Create a new repository**. Owner: your own account. Visibility: **Private**. Click **Create repository**.
2. Clone **your new repository** (not this template): `git clone <your repository url>`
3. Open the folder and run `jupyter notebook`.
4. After each part: `git add .`, `git commit -m "..."`, `git push`.
